# 新経費精算システム 操作手順書

対象：全社員
適用開始：2026年11月1日

## 1. 概要

- 紙の精算書と押印による承認を廃止
- 申請から承認、支払いまでをシステム上で完結
- 領収書はスマートフォンで撮影して添付

本システムの導入は、働き方を根本から変える画期的な一歩となる。

## 2. 事前準備

1. 社内ポータルの「経費精算」メニューを開く。
2. 社員番号とパスワードでログインする。
3. 初回のみ、振込先口座を登録する。
   - 給与の振込口座と同じ口座を指定
   - 口座名義はカタカナで入力
4. スマートフォンに専用アプリを入れ、同じ社員番号でログインする。

## 3. 領収書の登録

1. アプリを起動し、「領収書を撮影」を押す。
2. 領収書全体が枠に収まるように撮影する。
3. 自動で読み取られた日付・金額・支払先を確認する。
   - 読み取りに誤りがある場合は、その場で修正
   - 手書きの領収書は読み取り精度が低いため、必ず目視で確認
4. 「保存」を押す。

撮影した原本は、登録後も1か月間は手元で保管する。

つまり、紙の領収書をすぐに捨ててはいけないということである。

## 4. 精算の申請

1. パソコンまたはアプリで「新規申請」を開く。
2. 申請の種類を選ぶ。
   - 交通費
   - 出張旅費
   - 会議・接待費
   - その他の立替払い
3. 登録済みの領収書から、今回精算するものを選ぶ。
4. 用途と、関係する案件番号を入力する。
5. 内容を確認し、「申請」を押す。

申請の締め切りは毎月25日。締め切りを過ぎた申請は翌月の支払いとなる。

## 5. 承認の流れ

- 申請者 → 所属長 → 経理部の順に承認
- 5万円以上の申請は、部長の承認を追加
- 差し戻された場合は、コメントを確認して修正後に再申請

承認の状況は「申請一覧」の画面で確認できる。

## 6. よくある誤り

- 交通費で、定期区間を含む経路を申請
- 同じ領収書を二重に申請
- 会議・接待費で、参加者の氏名を未入力

いずれも差し戻しの対象。申請前に確認する。

ルールを正しく理解することは、すべての社会人にとって欠かせない基本である。

## 7. 問い合わせ先

- 操作方法：情報システム部（内線 2210）
- 精算の規程：経理部（内線 3105）

不明点は早めに問い合わせる。
