# 四十三歳で、合唱団に入った

先に書いておくと、これは歌がうまくなった話ではない。

去年の春、市の合唱団に入った。練習は週に一度、木曜の夜七時から九時まで、公民館の二階である。団員は三十一人で、私が入ったテノールは六人しかいない。

入る前に、ピアノ教室とどちらにするかで一か月迷った。ピアノは月謝が八千円で、時間は自分の都合で決められる。合唱団は月二千円だが、木曜の夜を毎週空けなければならない。決め手になったのは、見学の日に、隣の人の声が自分の胸に響いてくる感じがしたことだった。一人で弾くより、誰かと鳴らすほうが、私の場合はたぶん続く。

人は誰でも、新しいことを始めるときには不安を感じるものだ。

最初の三か月は、ほとんど声が出なかった。楽譜は読めるつもりでいたのに、ほかのパートにつられて、気づくとアルトの旋律を歌っている。指揮の先生には「テノールさん、迷子になってますよ」と何度も言われた。練習の帰り道、公民館の玄関の前で、ほかのテノールの人たちが「最初はみんなそうだった」と笑ってくれたのが救いだった。六人のうち四人は六十代で、いちばん若い私がいちばん下手だった。

つられないために、通勤の電車で、テノールの音だけを録音したものを毎日聞いた。片道二十五分、イヤホンの中で同じ八小節を繰り返すうちに、混んだ駅のホームで連れの背中を見つけるように、ほかの声の中から自分の音を拾えるようになった。毎日の小さな積み重ねが、やがて大きな力になるのだ。

歌うと、ストレスのもとになる物質が減ることが分かっている。実際、練習のある木曜は、会社で何があっても、帰りの足取りが軽かった。

秋の定期演奏会で、初めて舞台に立った。曲は五つで、そのうち二つは日本の古い唱歌だった。黒いズボンと白いシャツは、団の決まりで自分で用意する。客席は三百ほどで、半分くらいが埋まっていた。それはまさに、魂が震えるような奇跡の時間だった。正直に言えば、二曲目の途中で一小節早く入ってしまい、隣の小池さんに肘で軽くつつかれた。終わってから妻に「どこにいたか分からなかった」と言われて、少しうれしかった。目立たないことが、合唱では褒め言葉になる。

演奏会までの半年、週に二度の練習を私は一度も休まなかった。それだけは、自分をほめてもいいと思っている。

来年の春には、テノールに新しく二人入ってくる予定だ。一年前の私と同じ顔で、楽譜を握りしめているのだろう。迷子になっていたら、今度は私が音を取ってあげたい。

これからも、感謝の気持ちを忘れずに、一歩ずつ歩んでいきたい。
