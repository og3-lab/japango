# 正解表（1 組目・調整用）

組み立て方を決めるのに使った素材。素材は同じフォルダの t1〜t3。

採点の決まり:
- 直すべき箇所（F）: 直した＝1、半分（片方だけ・弱めただけ）＝0.5、残した＝0。削除して前後の意味が通れば直したとみなす
- 守るべき箇所（K）: 意味・数字・条件・書き手の調子が変わったら「保持違反」1
- 原文にない事実（主体・原因・数字・時期）を足したら「足した事実」1 件（F の得点とは別に数える）

## t1 技術記事（F 10・K 3）

| ID | 箇所 | 問題 | 直ったとみなす形 |
|---|---|---|---|
| F1 | 「今回は、…ご紹介していきたいと思います。」 | 中身のない前置き | 削る、または記事の要点を言う文に替える |
| F2 | 「この遅さが、現場の不満を静かに育てていました。」 | 擬人化・比喩 | 削る、または事実（利用者が待たされていた）で言う |
| F3 | 「キャッシュは、データベースの負荷をそっと肩代わりしてくれる頼もしい存在です。」 | 擬人化・中身のない評価 | 削る、または仕組みを平叙で言う |
| F4 | 「設定自体は地味ですが、これが…効きました。」 | 比喩動詞・中身なし | 削る、または結果の数字につなぐ |
| F5 | 「**とにかく**、**本当に**」 | 過剰な太字と強調語 | 強調語と太字を外す |
| F6 | 結果の段落の一文まるごと太字 | 過剰な太字 | 太字を外すか数字だけにする |
| F7 | 見出し「結論：」 | 見出しのコロン・中身のない見出し | コロンを外す、または中身を言う見出し |
| F8 | 「依存しているテーブルは分割できないので、…と考えています。」 | 判断した人・根拠が書かれていない | 主体を補うのではなく、根拠が無いことが分かる形にする／書き手に確かめる印を付ける。作った理由を足したら「足した事実」 |
| F9 | 「…背中をそっと押せたら嬉しいです。」 | 定型の結び | 削る |
| F10 | 「キャッシュは速さではなく、利用者の待ち時間を減らすための道具です。」 | 速さと待ち時間は同じことで、対比が成り立たない | 対比を外す、または削る |

| ID | 守るもの |
|---|---|
| K1 | 数字（900→300 ミリ秒、12 万→2 万件、60 秒、4 回、3 秒以上） |
| K2 | 「在庫数は 60 秒ずれても業務に差し支えない、と倉庫の担当者に確認してあります。」の条件と確認した相手 |
| K3 | 題の「3 倍」 |

## t2 障害報告（F 6・K 3）

| ID | 箇所 | 問題 | 直ったとみなす形 |
|---|---|---|---|
