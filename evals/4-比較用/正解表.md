
# 推敲比較の正解表（4 回目・2 つの推敲ツールを比べる素材・2026-10-22）

日本語の推敲ツール 2 つを比べるための素材。素材は同じフォルダの x1〜x3（x1 社内報告・x2 解説記事・x3 体験記）。どちらのツールの規則・カタログも見ずに書き、題材・文・比喩は素材 3（k1〜k3）と重ねていない。ID は F（直すべき箇所）・K（守るべき箇所）とする。

採点の決まり:
- 直すべき箇所（F）: 直した＝1、半分（片方だけ・弱めただけ）＝0.5、残した＝0。削除して前後の意味が通れば直したとみなす
- 守るべき箇所（K）: 意味・数字・条件・書き手の調子が変わったら「保持違反」1
- 原文にない事実（主体・原因・数字・時期・出典）を足したら「足した事実」1 件（F の得点とは別に数える）
- 書き直さず指摘を返す方式は、F は「指摘して、直し方が正しい」＝1、「指摘したが直し方がずれる」＝0.5。K は「直すよう指摘した」ら保持違反
- 「書き手に聞く箇所」（問題の欄に印）は、根拠や主体が原文に無い。主体・根拠を作って補ったら「足した事実」、削るか確かめる印を付けたら直したとみなす
- 確認欄（書き手に確かめたい点）で正しく聞いた箇所も直ったとみなす（本文を残していても 1。聞き方が箇所の問題とずれていれば 0.5）

迷いやすさ: 高＝もっともらしく読めて、直す・残すの判断が割れやすいもの。中＝気づけば判断は割れにくいもの。集計では得点を迷いやすさ別にも出す（方式の差は「高」に出るはず）。F は 3 本で中 10・高 9。

同じ本の中に、見かけの似た F と K を対で置いた。形だけで一括して削ると K を落とし、一括して残すと F を落とす。
- x1: F6「仕組みではなく、意識から」と K5「件数ではなく、対策につながった件数」（どちらも「〜ではなく」の対比）
- x2: F3「植物の声を聞くための扉」と K4「牛乳パック」（どちらも比喩）／F4「根腐れはほぼ防げます」と K5「黄色くなった鉢はありませんでした」（どちらも効果の言明）
- x3: F2「毎日の小さな積み重ねが…」と K4「目立たないことが、合唱では褒め言葉になる。」（どちらも段落末の一般化）／F4「魂が震えるような奇跡」と K3「駅のホームで連れの背中を見つける」（どちらも比喩）
