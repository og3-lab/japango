# 正解表（3 組目・迷う箇所を中心にした素材）

3 組目の素材。素材は同じフォルダの k1〜k3。2 組目（`../2-判定用/` の h1〜h3）で、比べた方式がどれも満点になり差が出なかったため、今回は「直すか残すかで迷う」箇所を中心にした。分かりやすい AI っぽさ（定型の決意・定型の締め）は各本 0〜1 か所にとどめ、見落としやすい F と、直したくなるが残すべき K を多くした。題材・文・比喩は 1 組目（t1〜t3）・2 組目（h1〜h3）と重ねていない。ID は 1・2 組目と区別するため M（直すべき箇所）・N（守るべき箇所）とする。

採点の決まり（1 組目と同じ）:
- 直すべき箇所（M）: 直した＝1、半分（片方だけ・弱めただけ）＝0.5、残した＝0。削除して前後の意味が通れば直したとみなす
- 守るべき箇所（N）: 意味・数字・条件・書き手の調子が変わったら「保持違反」1
- 原文にない事実（主体・原因・数字・時期）を足したら「足した事実」1 件（M の得点とは別に数える）
- 「書き手に聞く箇所」（問題の欄に印）は、根拠や主体が原文に無い。主体・根拠を作って補ったら「足した事実」、削るか確かめる印を付けたら直したとみなす

迷いやすさ: 高＝もっともらしく読めて、直す・残すの判断が割れやすいもの。中＝気づけば判断は割れにくいもの。集計では得点を迷いやすさ別にも出す（方式の差は「高」に出るはず）。

同じ本の中に、見かけの似た F と K を対で置いた（例: k1 の M6 と N2、k2 の M11 と N10、k3 の M17 と N15 はどれも「〜ではなく／というより」の対比）。形だけで一括して削ると K を落とし、一括して残すと M を落とす。
