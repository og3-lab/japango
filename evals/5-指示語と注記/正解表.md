# 正解表（5 組目・指示語と注記）

型 21c（指す中身を言わない指示語・形式名詞）と型 20b（文の途中に（）で注記を差し込む）だけを測る小さな素材。s1 が型 21c、s2 が型 20b。それぞれの型を足すときに、足す前と後の物差しで見つける役を走らせて比べるために作った。ほかの型の当たり（文末の単調など）は採点に入れない。s1 の題「議事録の要約を AI に頼むときに確かめていること」の「こと」は、記事全体が中身なので採点しない（直しても残しても点にしない）。rubric の型 21c・20b の例は、この素材とは別の文で書いてある（20b の残す例の読み仮名・略語・一覧の種別は、種類が同じで語は別）。

ほかの型の名前で直しても下の決まりでは点になるので、足した型が効いたかは、その型の名前で挙げた数（P ごとに 0 か 1）も別に数える。

採点の決まり:
- 直すべき箇所（P）: 直した＝1、半分（片方だけ・弱めただけ）＝0.5、残した＝0。削除して前後の意味が通れば直したとみなす。「書き手に聞く箇所」は、〔確認n〕の印を付けたか削ったら直したとみなす
- 守るべき箇所（Q）: 意味・数字・条件・書き手の調子が変わったら「保持違反」1
- 原文にない事実（主体・原因・数字・時期）を足したら「足した事実」1 件（P の得点とは別に数える）
- 指す先がはっきりしている指示語・形式名詞と予告の見出し（Q1〜Q5）を型 21c で、残してよいかっこ（Q7〜Q9）を型 20b で、直す・聞く指摘に挙げたら「誤検出」1 件（直した文の意味が変わらなくても数える）

## s1 議事録の要約（P 4〔うち書き手に聞く 2〕・Q 6）

| ID | 箇所 | 問題 | 直ったとみなす形 |
|---|---|---|---|
| P1 | 見出し「「短くまとめて」と頼むと、元の議事録に無いことが増える」 | 見出しの形式名詞「こと」が中身を隠している。見出しなので前に指す先が無く、中身（担当者の名前や期限）は後の本文にしか無い | 中身を言う見出しにする（例「「短くまとめて」と頼むと、議事録に無い名前や期限が足される」）。本文に無い中身（原因・数など）を足したら「足した事実」 |
| P2 | 「要約の最後の段落は、同じことの言い直しになりがちです。」 | 「同じこと」が何と同じかを言っていない。中身は次の文にある | 何の言い直しかを言う（例「要約の最後の段落は、各議題で決まったことを並べ直すだけになりがちです。」）、または次の文とまとめる |
| P3 | 「この作業には、1 本あたり 10 分ほどかかります。」 | 「この作業」の候補が直前の段落に 2 つ（議事録の言い方に戻す・発言者ごとの言い回しを残す）あり、どれを指すかが原文から決まらない | 書き手に聞く（〔どの作業に 10 分かかるか〕など）。候補の 1 つを選んで書き込んだら「足した事実」 |
| P4 | 「その会議の外で決まった話は、要約に入れないようにしています。」 | 「その会議」の指す先が本文に無い（それまでは会議一般と 12 本の議事録の話で、特定の会議が出ていない） | 書き手に聞く（〔どの会議を指すか〕など）。特定の会議を作って書いたら「足した事実」 |

| ID | 守るもの |
|---|---|
| Q1 | 「その文は議事録の言い方に戻します」の「その文」（直前に指す先が 1 つだけある） |
| Q2 | 「それぞれ議事録のまま残します」の「それぞれ」（指す先は同じ文の「発言者ごとの言い回し」） |
| Q3 | 「議事録に無い期限が入っていたことは、読み返すまで気づきませんでした。」の「こと」（中身は直前の節そのもの） |
| Q4 | 見出し「戻すものと残すもの」（名詞で終わる予告の見出しで、直後の 2 文が戻すもの〔議事録に無い名前や日付が入った文〕と残すもの〔発言者ごとの言い回し〕を言う） |
| Q5 | 見出し「読み返すときに見る点」（予告の見出しで、直後の文が見る点〔要約に出てくる名前と日付〕を 1 つに決める） |
| Q6 | 数字（12 本、4 本、10 分ほど） |

P1 と Q4・Q5 の線引き: P1 は「〜が増える」と言い切る見出しで、目次や拾い読みでは見出しだけが結論として読まれるので、直後の文に中身（担当者の名前や期限）があっても直す側に置く。Q4・Q5 は名詞で終わり、次に来る話の題を示すだけなので、直後の 1〜2 文で中身が決まれば残す（rubric の型 21c の見出しの例外）。

## s2 問い合わせ窓口（P 3・Q 4）
