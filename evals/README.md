## 走らせ方
1. 原稿 1 本ごとに、SKILL.md の 1〜4 を行う（見つける役には正解表を見せない。正解表のあるフォルダを丸ごと渡さず、原稿だけを別の作業フォルダに写してから渡す）
2. 同じ原稿で 3 回走らせる（見つける役の判断は回ごとにぶれるので、点のばらつきも見る）

## 採点の手順
採点は、直した本文と確認欄を正解表と照らして行います。人が採点するか、japango を走らせたのとは別の会話の AI に採点させます。AI に採点させるときは、どの方式の出力かが分からないようにファイルの名前を伏せます（例: V1〜V9 に付け替え、対応表は採点が終わるまで渡さない）。

正解表の「採点の決まり」に従って、1 本ごとに次を数えます。

- **直すべき箇所の点**: 直した＝1、半分（片方だけ・弱めただけ）＝0.5、残した＝0。削って前後の意味が通れば直したとみなす。「書き手に聞く箇所」は、〔確認n〕の印を付けたか削ったら直したとみなす
- **守るべき箇所の違反**: 意味・数字・条件・書き手の調子が変わったら 1
- **足した事実**: 原文に無い主体・原因・数字・時期を足したら 1 件（点とは別に数える）

AI に採点させるときの依頼文の例:

```
次の正解表の「採点の決まり」に従って、直した文章を採点してください。
正解表: <正解表.md のパス>（使うのは <原稿の名前> の節だけ）
元の原稿: <原稿のパス>
直した文章: <伏せた名前のファイルのパス>（末尾の確認欄も採点に含める）
出力: 箇所の ID ごとに 1 行（ID、点または違反、理由 1 文）。最後に、直すべき箇所の合計点、守るべき箇所の違反の数、足した事実の数と、その文の引用。
```

## 合格の目安
- 守るべき箇所の違反 0、足した事実 0
- 直すべき箇所の点は、比べたい方式（ほかの推敲の手順など）を同じ原稿・同じ採点で走らせ、それを下回らないこと
- 3 回の点のばらつきが 2 点以内

点は AI の採点による代わりの指標です。「人が書いたように読めるか」は、最後に人が読んで判断してください。
