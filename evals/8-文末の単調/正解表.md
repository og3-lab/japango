# 正解表（8 組目・文末の単調）

型 28（文末の単調）だけを測る小さな素材。w1 がです・ます調の紹介記事、w2 がだ・である調の技術メモ。型 28 の条件を改めるときに、改める前と後の物差しで見つける役を走らせて比べるために作った。ほかの型の当たりは採点に入れない。5〜7 組目と同じく、型を改めた側が作った。rubric の型 28 の例（「決めます。書きます。直します。」）は、note の記事の箇条から取った語で、この素材の文とは別。

この組を足したきっかけ: note の記事を読んだ書き手が、箇条の項目をまたいで「決めます。書きます。直します。読みます。残します。」と「〜ます。」が続くのに気づいた。改める前の型 28 は「文の長さも似ている段落だけ」に当て、段落ごとに数えていたので、箇条をまたぐ続きと長さのそろわない続きが外れた。記事の文は素材に入れていない（物差しを改めた後に、記事そのものを別に 1 回通した）。

ほかの型の名前で直しても下の決まりでは点になるので、型 28 が効いたかは、型 28 の名前で挙げた数（P ごとに 0 か 1）も別に数える。

採点の決まり:
- 直すべき箇所（P）: 直した＝1、半分＝0.5、残した＝0。「直した」は、その続きに同じ形の文末が 3 文続く所が残っていないこと。続きの中の別の文を直して切れていても 1。直した文が隣と新しく 3 文続きを作ったら半分
- 守るべき箇所（Q）: 意味・数字・条件・書き手の調子が変わったら「保持違反」1。です・ます調の文を「〜する。」にした、だ・である調の文を「〜です。」にしたのも保持違反
- 原文にない事実（主体・原因・数字・時期・動作）を足したら「足した事実」1 件（P の得点とは別に数える）
- Q1〜Q4（当てない続き）を型 28 で直す・聞く指摘に挙げたら「誤検出」1 件（直した文の意味が変わらなくても数える）

## w1 道具の紹介記事（P 3・Q 6）

| ID | 箇所 | 問題 | 直ったとみなす形 |
|---|---|---|---|
| P1 | 冒頭の段落「総務部の 4 人で使っています。予約の取り消しも同じ画面でできます。毎朝 9 時に、その日の空き状況を流しています。」 | 「〜ます。」が 3 文続く（「〜ています」も同じ形に数える）。文の長さはそろっていない | 3 文目（または続きの中のどれか 1 文）の文末を別の形にする（例「毎朝 9 時に流しているのは、その日の空き状況です。」）。「〜ています」を別の形とみなして残したら 0 |
| P2 | 「予約の流れ」の 1 文の段落と箇条の項目「受け付ける」: 「…行います。」「…取り出します。」「…聞き返します」 | 短い段落と箇条の項目をまたいで「〜ます」が続く（「確かめる」の項目まで 6 文） | 続きの 3 文目「読み取れなかったときは、聞き返します」か、その前後の文の文末を替えて、3 文続きを切る（例「読み取れなかったときは、聞き返すのがボットの返事です」のように「です」で言う）。「聞き返すことになっています」のように語尾が「ます」のままなら 0 |
| P3 | 箇条の項目「確かめる」: 「…確かめます。空いていれば予約を入れます。重なっていれば、近い時間の空きを 2 つ示します」と「知らせる」の「…送ります」 | P2 から続く「〜ます」の 4〜7 文目 | 6 文目「重なっていれば、近い時間の空きを 2 つ示します」か、その前後の文の文末を替えて、3 文続きを切る。P2 と P3 の両方で、項目の中だけで直し、項目をまたいで 1 文につないでいないこと |

| ID | 守るもの |
|---|---|
| Q1 | 番号付きの手順「1. …開きます。2. …送ります。3. …確かめます。」（手順書の慣習として残す。文末を替えたら誤検出） |
| Q2 | 見本として引用した「送った文: 午後に 1 時間使います。」「送った文: 3 階の部屋を押さえます。」（前の文「ボットは聞き返します。」と合わせて数えない。引用を書き換えたら保持違反と誤検出） |
| Q3 | 「入れてみて」の 2 つの段落の境目（「…入ります。」「…数人います。」｜「…持ちます。」）。3 文の段落どうしの境目なので切って数える（1 段落の中は 2 文続きまで） |
| Q4 | 「1 回の予約は 2 時間までです。」と「聞き返しは、1 日に 3 件ほどありました。」の前後（同じ形が続かない） |
| Q5 | 数字と条件（4 人、毎朝 9 時、14 時から 1 時間、2 つ、2 時間まで、1 日に 3 件ほど、1 日 20 件ほど、週に数人） |
| Q6 | です・ます調（「〜する。」の文が 1 つも入らない） |
