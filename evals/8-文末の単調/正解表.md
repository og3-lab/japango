# 正解表（8 組目・文末の単調）

型 28（文末の単調）だけを測る小さな素材。w1 がです・ます調の紹介記事、w2 がだ・である調の技術メモ、w3 がです・ます調のアプリの案内。型 28 の条件を改めるときに、改める前と後の物差しで見つける役を走らせて比べるために作った。ほかの型の当たりは採点に入れない。素材は、5〜7 組目と同じく型を改めた側が作った。rubric の型 28 の例（「決めます。書きます。直します。」）は、note の記事の箇条から取った語で、この素材の文とは別。

この組を足したきっかけ: note の記事を読んだ書き手が、箇条の項目をまたいで「決めます。書きます。直します。読みます。残します。」と「〜ます。」が続くのに気づいた。改める前の型 28 は「文の長さも似ている段落だけ」に当て、段落ごとに数えていたので、箇条をまたぐ続きと長さのそろわない続きが外れた。その後、公開した記事を読んだ書き手が「ます。ます。ます。」がまだ続くと指摘した。「〜ました」「〜ません」を別の形に数えていたので、「直します。残します。見つけられません。」のような続きが外れていた。そこで、語尾の文字ではなく述語の種類（動詞／名詞・形容詞／体言止め／問い・お願い）で数え、時制と打ち消しは続きを切らない弱い変化とした。冒頭の段落を 4 文の続きに改め、対比と重なる 3 文の続き（今の D2）と、打ち消しの混ざる長い続きの w3 を足した（2026-10-23）。記事の文は素材に入れていない（物差しを改めた後に、記事そのものを別に 1 回通した）。

正解表を作り直した理由: 前の版は、型を改めた側（規則の作り手）が数えて作った。読者役（pro-reader）2 人に読ませたら、作り手の数えと食い違った。作り手が守る所にした w2 の「〜た」5 文と w3 の「つながないもの」を、2 人とも単調と聞いた。作り手が直す所にした w1 の「受け付ける」の項目と w3 の「読み取りの決まり」の箇条を、2 人とも単調でないと聞いた。そこで 2026-10-23 に、2 人が一致した所を P・Q とし、分かれた所は新しい区分 D（どちらでもよい）とした。1 人目は型 28 で直した版と原文を、2 人目は原文だけを読んだ。

ほかの型の名前で直しても下の決まりでは点になるので、型 28 が効いたかは、型 28 の名前で挙げた数（P ごとに 0 か 1）も別に数える。

採点の決まり:
- 直すべき箇所（P）: 直した＝1、半分＝0.5、残した＝0。「直した」は、その箇所の「直ったとみなす形」に合うこと。直した文が隣と新しく 3 文続きを作ったら半分
- 直ったとみなす形: 続きの文の文末の種類を替える直しに加えて、隣の文とつなぐ直し（「〜が、」「〜し、」「〜て、」などで 2 文を 1 文にする）を第一の正解とする。つなぐときは、原文の 2 文のどちらにも無い語・主語・因果を足さない。です・ます調の文で、述語を無理に「〜のは、X です」「〜です」へ替えた直し（例「手で直すことも可能です」「読み取れなかったときの返事は、聞き返しです」）は半分（0.5）。読者役が、手順書の読み上げのように聞こえると判定したため
- 時制の P: 時制が中身と合わない所。直す・書き手に聞く（ask）のどちらも 1
- 守るべき箇所（Q）: 意味・数字・条件・書き手の調子が変わったら「保持違反」1。です・ます調の文を「〜する。」にした、だ・である調の文を「〜です。」にしたのも保持違反
- どちらでもよい箇所（D）: 読者役 2 人の判断が分かれた所。直しても残しても点にしない。誤検出にも数えない。ただし直したときの保持違反・足した事実は数える
- 原文にない事実（主体・原因・数字・時期・動作）を足したら「足した事実」1 件（P の得点とは別に数える）
- 誤検出: Q を型 28 で直す・聞く指摘に挙げたら 1 件（直した文の意味が変わらなくても数える）
