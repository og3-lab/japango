# 正解表（2 組目・判定用）

組み立て方を決めた後に、別に作った素材。素材は同じフォルダの h1〜h3。1 組目（`../1-調整用/` の t1〜t3）とは題材・文・比喩を重ねず、作り方と採点の決まりは 1 組目と同じにした。ID は 1 組目（F・K）と区別するため G・L とする。

採点の決まり（1 組目と同じ）:
- 直すべき箇所（G）: 直した＝1、半分（片方だけ・弱めただけ）＝0.5、残した＝0。削除して前後の意味が通れば直したとみなす
- 守るべき箇所（L）: 意味・数字・条件・書き手の調子が変わったら「保持違反」1
- 原文にない事実（主体・原因・数字・時期）を足したら「足した事実」1 件（G の得点とは別に数える）
- 「書き手に聞く箇所」（問題の欄に印）は、根拠や主体が原文に無い。主体・根拠を作って補ったら「足した事実」、削るか確かめる印を付けたら直したとみなす

## h1 技術記事（G 9・L 4）

| ID | 箇所 | 問題 | 直ったとみなす形 |
|---|---|---|---|
| G1 | 「変化の激しい現代の開発において、テストの速さは誰もが向き合うべきテーマです。」 | 時代の決まり文句で始まる中身のない前置き | 削る、または記事の要点（22 分→7 分）を言う文に替える |
| G2 | 「一般に、開発者の多くは待ち時間が 10 分を超えると別の作業に移ってしまうと言われています。」 | 根拠の無い一般化（「と言われています」） | 削る、または出典が要る印を付ける。出典・調査名を作ったら「足した事実」 |
| G3 | 「**実行時間の記録**」「**4 つの組**」「**4 台で同時に**」 | 1 文の中の語句ごとの太字 | 太字を外す |
| G4 | 「とはいえ、並列化に課題がないわけではありません。」 | 二重否定 | 「課題もあります」など肯定で言う、または削って次の文（データベースの件）につなぐ |
| G5 | 「この増え方は許容範囲と判断されました。」 | 判断した人・根拠が書かれていない受け身（書き手に聞く箇所） | 主体・根拠を確かめる印を付ける、または根拠が無いと分かる形にする。判断者や予算の数字を作ったら「足した事実」 |
| G6 | 「ほかのチームでも、同じやり方で待ち時間が半分以下になったと聞いています。」 | どのチームか・誰から聞いたかが無い伝聞（書き手に聞く箇所） | 削る、または確かめる印を付ける。チーム名・数字を作ったら「足した事実」 |
| G7 | 「速さだけでなく、安心感、そして心地よさまでもが手に入りました。」 | 三つ並べの水増し・中身のない評価 | 削る |
| G8 | 「つまり、テストを 4 つに分けて…減らせたということです。」 | 結果の段落の言い直し（まとめの段落） | 削る |
| G9 | 「テストの並列化は、…取り組みと言えるでしょう。」 | 「〜と言えるでしょう」の中身のない結び | 削る |

| ID | 守るもの |
|---|---|
| L1 | 数字（約 1,900 件、22 分→7 分、4 台、15 分、合計の利用時間 22 分→28 分） |
| L2 | 「件数で均等に分けるのではなく、前回の実行時間の合計がそろうように」の対比と、その理由（遅いテストが 1 組に偏り 15 分かかった） |
| L3 | 組分けの条件（main ブランチの最新の実行から取る、記録の無いテストはいちばん短い組に入れる） |
| L4 | 「遅いテストの上位 20 件を、11 月中に」の件数と時期 |

## h2 障害報告（G 7・L 4）

| ID | 箇所 | 問題 | 直ったとみなす形 |
|---|---|---|---|
| G10 | 「問い合わせは当初、利用者側の回線の問題として扱われました。」 | 誰がそう扱ったか・なぜかが無い受け身（書き手に聞く箇所） | 主体を確かめる印を付ける。「窓口の担当者が」など主体を作ったら「足した事実」 |
| G11 | 「原因の特定に 1 時間半近くかかったのは痛手だった。」 | です・ます の文書に だ が混ざる | 文体をそろえる、または削る |
| G12 | 「証明書の期限切れ――それは誰もが知っていながら、誰もが見落としてしまう落とし穴です。」 | ダッシュでの溜め・根拠の無い一般化・決まった比喩 | 削る |
| G13 | 「今回の障害は、証明書の問題ではなく、期限の問題でした。」 | 期限切れは証明書の問題そのもので、対比が成り立たない | 削る、または原因（設定の漏れ・手順書に項目が無い）を言う文に替える |
| G14 | 「二度とこのような事態を招かぬよう、全社一丸となって再発防止に努めさせていただきます。」 | 箇条書きの中の中身のない決意・過剰な敬語 | 削る |
| G15 | 「ほかのシステムの証明書も点検し、問題がないことが確認されています。」 | 誰が・どのシステムを・いつ点検したかが無い受け身（書き手に聞く箇所） | 確かめる印を付ける。点検者・件数・システム名を作ったら「足した事実」 |
| G16 | 「…示しているのかもしれないと考えられます。」 | ぼかしの重ね（かもしれない＋考えられる）・中身のないまとめ | 削る |

| ID | 守るもの |
|---|---|
| L5 | 時刻（8 時 00 分・8 時 25 分・9 時 50 分・11 時 20 分）、54 人、締め日を 10 月 6 日まで延ばしたこと |
| L6 | 「社外から」接続できなかった・「社内からは使えていました」の条件 |
| L7 | 「移設の手順書に、この設定の項目はありませんでした。」（原因の中身） |
| L8 | 対策の期日と条件（10 月 17 日まで、期限の 30 日前と 7 日前、情報システム課の共有チャンネル） |
