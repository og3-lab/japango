# 正解表（6 組目・助詞の重なり）

型 20c（同じ助詞を違う働きで 1 文に重ねる）だけを測る小さな素材。型を足すときに、足す前と後の物差しで見つける役を走らせて比べるために作った。ほかの型の当たりは採点に入れない。rubric の型 20c の例は、この素材とは別の文で書いてある。

ほかの型（型 20 など）の名前で直しても下の決まりでは点になるので、足した型が効いたかは、その型の名前で挙げた数（P ごとに 0 か 1）も別に数える。

採点の決まり:
- 直すべき箇所（P）: 直した＝1、半分＝0.5、残した＝0。P1 は、文を分けたが分けた文に主題も主語も無い（「自由です。」だけで何が自由か決まらない）か、読者が先に知りたい情報（どこで開くか）を後ろに回したら半分
- 守るべき箇所（Q）: 意味・数字・条件・書き手の調子が変わったら「保持違反」1
- 原文にない事実（主体・原因・数字・時期・動作）を足したら「足した事実」1 件（P の得点とは別に数える）。文を分けるときに原文に無い動作・手順（申し込む・登録するなど）を足すのも数える
- 同じ働きの並び（Q1・Q2・Q3）を型 20c で直す・聞く指摘に挙げたら「誤検出」1 件（直した文の意味が変わらなくても数える）

## u1 勉強会の案内（P 3・Q 4）

| ID | 箇所 | 問題 | 直ったとみなす形 |
|---|---|---|---|
| P1 | 「勉強会は参加自由で、本社の会議室とオンラインで開きます。」 | 1 つ目の「で」は「参加自由だ」の続き（様子）、2 つ目は開く場所・手段。読者は 2 つ目で係り方を組み直す。参加の条件と開く場所という種類の違う情報を 1 文に詰めている | 文を分けて主題を立てる（例「勉強会は本社の会議室とオンラインで開きます。参加は自由です。」）。誤りの例: 「勉強会は参加自由です。本社の会議室とオンラインで申し込んで参加できます。」は、原文に無い動作（申し込む）を足したので「足した事実」1、場所が後ろに回ったので半分 |
| P2 | 「最初の回では、経理部の先月の締めの作業の手順の見直しの結果を紹介します。」 | 「の」が 6 つ続き、持ち主・時・中身の働きが混ざる。読者はどの語がどの語に係るかを組み直す | 「の」を減らし、係り方が 1 通りに読める形にする（例「最初の回では、経理部が先月の締め作業の手順を見直した結果を紹介します。」）。「見直した」は原文の「見直し」から言えるので足した事実にしない。原文に無い動詞（作った・まとめた など）を足したら「足した事実」 |
| P3 | 「質問は講師に開始前にチャットに書いて送ってください。」 | 「に」が 3 つ（相手・時・書く先）並び、どの「に」が「送る」に係るかを組み直す | 文を分けるか語順を変えて「に」の働きが読み分けられる形にする（例「質問はチャットに書いて、開始前に講師へ送ってください。」）。「開始前」を「開始前までに」と書き換えたら時の条件が変わるので保持違反 |

| ID | 守るもの |
|---|---|
| Q1 | 「1 回目は会議室 A で、2 回目は会議室 B で開きます。」（2 つの「で」はどちらも場所の並び） |
| Q2 | 「資料は紙でもメールでも配ります。」（2 つの「で」はどちらも手段の並び） |
| Q3 | 「表計算の練習用のファイルは、前日までに配ります。」（「の」は 2 つまで） |
| Q4 | 条件と時（参加自由、本社の会議室とオンライン、会議室 A・B、前日まで、開始前） |

この型を足したきっかけ: note の記事で、AI が別の指摘を直したときに「japango は無料で、Claude Code と Codex で使えます。」という文を新しく作った（1 つ目の「で」は様子、2 つ目は使う場所）。書き手は「japango は Claude Code と Codex で使えます。料金は無料です。」を採った。途中で AI が出した「japango は無料です。Claude Code と Codex に入れて使えます。」は、原文に無い動作（入れて）を足し、料金を先に言い、何が無料かを主題で立てていないので却下された。P1 の誤りの例は、この却下された直しと同じ 3 点で作った。この記事の文は素材に入れていない（物差しを足した後に別に 1 回だけ測った）。

合計: P 3 か所、Q 4 か所。
